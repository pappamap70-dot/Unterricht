LebWerk

Notenverwaltung und Lernberichte – läuft komplett auf deinem eigenen Rechner

LebWerk für Windows herunterladen

Version 1.1.27 · Windows 10/11 · rund 22 MB · keine Installation von Administratorrechten nötig

⚠️ Windows wird dich warnen – das ist normal

Der Installer ist nicht bei Microsoft registriert (dafür bräuchte es ein kostenpflichtiges Zertifikat). Deshalb blendet Windows beim Start einen blauen Kasten ein: „Der Computer wurde durch Windows geschützt".

  1. Im blauen Fenster auf „Weitere Informationen" klicken.
  2. Dann erscheint der Knopf „Trotzdem ausführen" – darauf klicken.
  3. Die Installation läuft danach ganz normal durch.

Falls dein Browser den Download blockiert: im Download-Bereich auf „Beibehalten" gehen.

🚀 Die ersten Minuten

  1. LebWerk starten. Beim ersten Start fragt es dich, welche Fächer du unterrichtest.
  2. Zum Ausprobieren: Einstellungen → Musterdaten laden. Damit hast du eine Beispielklasse mit Noten, ohne eigene Daten eintippen zu müssen.
  3. Erst danach eigene Klassen anlegen – oder Schülerlisten als CSV importieren.
  4. Bewertungen erfassen, Noten ansehen, Lernberichte erzeugen.
Deine Daten bleiben bei dir. LebWerk sendet nichts ins Internet – keine Cloud, kein Konto, keine KI-Dienste. Alles liegt in Dokumente\LebWerk auf deinem Rechner. Die Lernberichte entstehen aus hinterlegten Mustersätzen, nicht aus einem Online-Dienst.

🔐 Passwortschutz – bitte vorher lesen

Du kannst deine Daten mit einem Passwort verschlüsseln (Einstellungen → Sicherheit). Das ist sinnvoll, weil es um Schülerdaten geht.

Wichtig: Dieses Passwort kann niemand zurücksetzen – ich auch nicht. Wenn du es vergisst, sind die Daten unwiederbringlich verloren. Schreib es dir auf, bevor du es vergibst.

💾 Sicherung einrichten

LebWerk legt automatisch Backups an. Zusätzlich lohnt sich ein zweiter Ort: Einstellungen → Daten & Backup → Ordner wählen, dort einen USB-Stick oder ein Netzlaufwerk eintragen. Dann liegt der Arbeitsstand nicht nur auf einem Gerät.

🔄 Updates

Beim Start schaut LebWerk nach, ob eine neuere Version bereitliegt, und fragt dich dann. Ein Klick genügt – Herunterladen und Installieren passieren von selbst, deine Daten bleiben unangetastet. Du kannst die Frage jederzeit mit „Später" wegklicken.

🧪 Du testest – worauf ich hoffe

Das hier ist eine Testversion. Besonders hilfreich sind Rückmeldungen zu:

  • Stellen, an denen du nicht weiterwusstest oder etwas anderes erwartet hast
  • Fehlermeldungen (gern mit Screenshot)
  • Dinge, die für deinen Unterricht fehlen
  • ob die Lernberichte sprachlich brauchbar sind
Für den ersten Durchgang: bitte mit den Musterdaten oder mit abgekürzten Namen arbeiten, nicht gleich mit dem vollständigen echten Klassensatz.
LebWerk entsteht nebenbei für den eigenen Unterricht – Rückmeldungen sind ausdrücklich erwünscht.
